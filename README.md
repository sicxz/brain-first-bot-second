# Brain First, Bot Second

Materials for teaching students to study with Gemini Notebook (formerly NotebookLM) without letting it do the thinking. Every version works for any course and any discipline.

| Version | For | Site path |
| --- | --- | --- |
| Faculty deck | Any instructor presenting the talk. Speaker notes, presenter guide, two-screen mode, research and study-method links. | `/faculty/` |
| Interactive deck | Running the talk with a class. Polls, timers, predict-and-reveal, a spot-the-mistake game, optional 20-minute sprint. | `/interactive/` |
| Walk-through | Students reading on their own. Check-yourself questions and the optional sprint. | `/walkthrough/` |
| Tutorial | Students building a study notebook for any reading, slides or unit. About 30 minutes. | `/tutorial/` |
| Original talk | The ITGS 196 version presented in October 2026. Kept as a record. | `/itgs-196/` |

## Folder layout

```
src/            page sources (HTML fragments, also publishable as Claude artifacts)
  hub.html        landing page
  original/       the ITGS 196 talk; the decks are generated from it
  faculty/        GENERATED by scripts/faculty.py
  interactive/    GENERATED by scripts/interactive.py
  walkthrough/    edited by hand
  tutorial/       edited by hand
img/            mascot images shared by every page
scripts/        build scripts
docs/           GENERIC-SPEC.md (shared wording rules) and the original talk script
site/           the built site that gets deployed (generated, committed)
```

## Build

Requires Python 3. No other dependencies.

```bash
python3 scripts/build.py
```

The build:

1. Makes a course-neutral copy of `src/original/index.html` (`scripts/generalize.py`).
2. Generates `src/faculty/` and `src/interactive/` from that copy.
3. Wraps every page in a full HTML document, points links at site paths, and writes `site/`.

Edit `src/original/index.html`, `src/walkthrough/`, `src/tutorial/` or `src/hub.html`. Don't edit `src/faculty/` or `src/interactive/` directly; change `scripts/faculty.py` or `scripts/interactive.py` instead. Run the build and commit `site/` with your changes.

To preview locally:

```bash
python3 -m http.server 8000 --directory site
```

Then open http://localhost:8000.

## Deploy on GitHub Pages

1. Push this repository to GitHub.
2. In the repository, open **Settings → Pages** and set **Source** to **GitHub Actions**.
3. Every push to `main` runs `.github/workflows/pages.yml`, which builds and publishes `site/`.

The site uses relative links, so it works at a project address like `https://<user>.github.io/brain-first-bot-second/`.

## Deploy on Vercel

1. In Vercel, choose **Add New → Project** and import the GitHub repository.
2. Keep the defaults. `vercel.json` tells Vercel to serve the committed `site/` folder with no build step.
3. Every push to `main` deploys again.

Vercel does not run the Python build, so run `python3 scripts/build.py` and commit `site/` before you push.

## Images

The Codex pet, Dots and Jolly images are launch art from OpenAI and Meta, taken from press coverage. Clawd is redrawn from the Claude Code terminal sprite. They are used here to comment on AI mascots. Check that this use fits your institution's policies before you publish the site.
